# Blazing Butler

Automated farming assistant for **Naruto Shippuden: Ultimate Ninja Blazing** (Ninja Road, Phantom Castle, Trial Missions, and Standard Missions).

## Setup & Requirements
1. **Download:** Grab the latest `BlazingButler.zip` from the **[Releases](../../releases)** page and extract the entire folder. *(Keep `BlazingButler.exe` inside the extracted folder alongside `_internal` and `templates`.)*
2. **Emulator Resolution:** Set your emulator display to **720 × 1280** (Portrait, 280 DPI).
3. **ADB Debugging:** Enable **ADB** in your emulator settings before starting the bot.
4. **Launch:** Open `BlazingButler.exe` and enter your access code. Whenever a new release is published here, the Butler will prompt you to auto-update after unlocking.

## Hotkeys
* **F3** — Pause / Resume
* **F4** — Finish current run, then stop & print session report
